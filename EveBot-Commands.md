# 🧠 Eve Bot Command Matrix

Eve Bot uses a strict **heuristic semantic evaluator**. Instead of relying on expensive external LLMs (Large Language Models), Eve maps specific chat strings directly to powerful, real-time database queries using Supabase context.

She is fully aware of your logged-in session, and can format responses organically using Markdown tables or custom interactive React UI Cards (`[QR_CARD=]`).

---

## 🗣️ Supported Commands

Here are the various conversational hooks available inside Eve Bot.

### 1. 🎫 The Advanced Check-in Flow
*   **Triggers**: `give qr`, `show qr`, `my qr`
*   **Behavior**: 
    1. Eve detects you're asking for a QR code but lacks context.
    2. She asks: *"Which event do you need the QR code for?"*
    3. You respond with an event name (e.g., *"Dance event"*, *"test event"*).
    4. She scans your active database registrations and performs a string-search for the best matching event name.
    5. She injects a dynamic `[QR_CARD=]` payload into the chat.
    6. The UI intercepts this payload, drops the markdown engine, and securely renders an **Interactive Event Card** with a dark-mode compliant "View QR" button.
    7. Clicking the button opens the native Club-Eve QR Check-in Modal directly over the chat interface.

### 2. 📅 Database Exploration Commands
*   **Triggers**: `upcoming`, `new`, `explore`
*   **Behavior**: Scans the core `events` table for campus activities. It zeros out today's clock and physically checks the date array to only produce events that haven't expired. Outputs identically into a **GitHub Flavored Markdown Table**.

### 3. ✅ Active Registration Queries
*   **Triggers**: `registered`, `my event`
*   **Behavior**: Scans the many-to-one `registrations(events)` relational join. Ignores past elapsed events and pulls down a tabulated structure of any events you are holding a ticket for.

### 4. 🕰️ Historical Extraction
*   **Triggers**: `past event`, `previous events`, `completed event`
*   **Behavior**: Conducts the inverse of the registration check. Evaluates dates strictly earlier than midnight today, or events that a manager specifically flagged as `'completed'`. Provides an organized list of past participation.

### 5. 🪪 Identity Reconnaissance
*   **Triggers**: `profile`, `my info`, `who am i`, `usn`
*   **Behavior**: Formats the securely captured server-side `profile` payload into a bulleted dossier, reflecting what internal state the application knows about you (USN, Role, Department).

### 6. 🚨 Operator Assistance
*   **Triggers**: `help`, `what can you do`, `commands`
*   **Behavior**: Dumps a markdown table detailing a quick-reference guide of exactly what conversational hooks work with her parser.

## 💎 Aesthetically Focused Engineering
Every line generated by the backend ignores standard unstyled outputs. Text logic uses `.toLocaleDateString()`, and custom component interpolation is utilized under the hood. Theme toggling perfectly integrates into Eve bot, meaning Dark, Light, and Pastel themes recursively pass down without clash logic!
