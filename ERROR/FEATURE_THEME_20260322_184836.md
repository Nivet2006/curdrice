# Feature Summary: Dark/Light Mode Support

**Date:** 2026-03-22
**Components:** `app/globals.css`, `app/layout.tsx`, `components/shared/ThemeToggle.tsx`, `components/shared/Navbar.tsx`, `app/(auth)/login/page.tsx`

## Overview
Implemented a global theme system that allows users to toggle between a polished light theme and a high-contrast dark theme. The system is designed to gracefully handle existing hardcoded Tailwind utility classes while providing a consistent, transition-ready appearance across the entire application.

## Key Features
1. **Dynamic Theme Switcher**: 
   - New `ThemeToggle` component with Sun/Moon icons.
   - Fluid thumb-sliding animation (300ms duration).
   - `localStorage` persistence and automatic `prefers-color-scheme` detection.
2. **Robust CSS Architecture**:
   - Refactored `globals.css` with semantic CSS variables (`--bg`, `--fg`, `--accent`, etc.).
   - Implemented "Brutal Overrides": Custom CSS selectors that effectively force hardcoded Tailwind hex values (like `bg-[#ffffff]` or `text-[#0a0a0a]`) to respect the active theme without needing to refactor every single component file.
3. **Semantic Integrity**: 
   - Maintained semantic colors (Green for success, Red for errors, Amber for warnings) with contrast-optimized variants for dark mode.
4. **Site-Wide Transition**: 
   - Applied global CSS transitions (0.2s) to facilitate smooth, non-jarring switching between themes.

## Deployment States
- **Authenticated Views**: Toggle available in the global `Navbar` next to the user profile.
- **Unauthenticated Views**: Toggle manually integrated into the `Login` page standalone layout.

## Reset
Execution of a full environment reset (`taskkill` and `.next` purge) ensures the new CSS-in-JS and global stylesheet bindings are active.
